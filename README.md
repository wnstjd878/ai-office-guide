# AI 오피스

AI 오피스는 사장님 PC에서 도는 업무용 데스크톱 앱입니다. 사장님 PC에 설치된 Claude Code를 팀원처럼 나눠 맡기고, 경영 탭에서 매출과 비용을 모아 봅니다.

## 구글 메일을 연결하는 이유

경영 탭은 아래 메일을 찾아 매출과 비용에 넣습니다.

1. 국세청이 보낸 전자세금계산서 메일 (hometaxadmin@hometax.go.kr)
2. 카드사 이용대금 명세서 메일
3. 은행 입출금 알림을 메일로 전달한 것
4. 결제대행사 정산 안내 메일

메일은 읽기만 합니다. 보내거나 지우거나 고치지 않습니다.

구글 연결에는 사장님 구글 계정 안에 직접 만든 앱을 씁니다. 그래서 개발자 계정이나 개발자 서버는 연결에 끼지 않습니다.
